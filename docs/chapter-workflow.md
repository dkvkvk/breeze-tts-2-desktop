# 章节配音工作流

「章节配音」将旁白和角色对话按原文顺序组织成一份可重复编辑的项目。

1. 在「音色库」导入获授权的参考录音，或用「音色克隆」保存所需音色。
2. 导入 UTF-8 TXT 或粘贴章节。已有「角色名：台词」标签的内容选择剧本模式。小说模式会保留旁白，并将引号中的台词标为「待确认」。
3. 核对每段台词的归属，为角色选音色。旁白可沿用模型默认音色。「只看待确认」可筛出需要核对的台词。可批量指派角色，也可以合并同一人物的别名。
4. 输入章节名称并点击「保存项目」。下次从历史打开，原文、角色选择和未确认台词都会恢复。点击「生成整章」也会保存项目。
5. 生成后按段试听。修改一句后可点该段「重录」，其余符合当前设置的片段会继续复用。
6. 导出 WAV 和按实际时长计算的 SRT。勾选「字幕显示角色名」可在字幕中保留角色标识。

生成中可点「停止生成」，已经完成的片段会保存在本机。中断或退出后，重新打开项目并加载原模型，点击「继续生成」即可从缺失片段开始。未完成时也可以试听和导出从开头连续生成的部分。

章节历史也会显示用 [HTTP 或 MCP 提交的本机 Agent 项目](agent-api.md)。打开后可核对台词、继续合成和局部重录。同一项目沿用同一个任务 ID。
