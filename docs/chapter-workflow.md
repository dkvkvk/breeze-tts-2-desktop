# 章节配音工作流

「章节配音」把旁白和角色对话排在同一张台词列表中，所有片段按原文顺序合成。

1. 准备参考音色。可在「音色库」导入获授权的参考录音，或用「音色克隆」保存音色。
2. 导入 UTF-8 TXT 或粘贴章节。带有「角色名：台词」的内容选择剧本模式。小说模式会将引号中的台词标为「待确认」，并保留周围的旁白。
3. 解析后，为各角色选择参考音色。旁白可以沿用默认音色。核对台词归属，可批量选择多句指定角色，或合并同一人物的别名。
4. 生成后按段试听。如果只修改了一句，用该段的「重录」更新音频。重新生成整章时会复用台词和音色设置均未变更的片段。
5. 导出整章 WAV 和按实际时长计算的 SRT。勾选「字幕显示角色名」可在字幕中保留角色标识。

当前生成结果保留在本次窗口内。退出应用前请导出所需文件。片段无法生成时，可在问题处理后继续，已有的完整片段会保留。
