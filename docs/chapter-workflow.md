# 章节配音工作流

1. 在「章节配音」粘贴正文或导入 UTF-8 TXT，点击「识别对白并标注」。保留原有段落、引号和换行。内置识别支持常见角色名标签和带明确说话人提示的对白。
2. 用鼠标拖选连续正文中的任意文字。在弹出的工具栏选用章节角色或音色库里已有的音色，也可以填入名称和描述新建音色。新建功能会在本地模型合成参考音频，保存到音色库并应用到所选内容。
3. 彩色下划线表示对应的角色音色。点已有下划线可查看角色和音色，再改标或试听。虚线表示说话人待确认。自动识别发现明确角色名时，可在「章节角色与音色」里一次为该角色设置音色。
4. 「一键配音色」使用平静旁白、清亮女声、自然男声和沉稳长者，为尚未配置音色的角色补齐音色。
5. 如需识别待确认的对白，展开「AI 标定」，填入兼容 OpenAI Chat Completions 的 API 基础地址（例如 `http://127.0.0.1:11434/v1`）和实际的模型名称。在线服务的 API 密钥由 Windows 加密保存在本机。点击「生成建议」会将这一章发到填写的服务。逐条核对说话人和音色，再点击「应用建议」。也可以用「复制 Agent 任务」交给本机 Agent，然后点击「读取 Agent 建议」。
6. 点击「保存项目」保留正文、音色批注和生成进度。下次从历史打开即可继续。需要修改正文时，可通过「编辑正文」返回输入区。对正文重新识别前会提示，此操作会重建音色批注。
7. 生成后可试听整章，或选中一条已有批注单独试听和重录。WAV 与 SRT 按合成音频实际时长对齐，字幕可附带角色名。

生成中可点「停止生成」。重新打开项目并加载原模型后，点击「继续生成」从缺失片段开始。章节历史也可以打开通过 [HTTP 或 MCP](agent-api.md) 提交的 Agent 项目。
