## 音色与表演

以下音色是按本章人物状态拟定的试音方向。每个角色全章沿用同一音色，按场景变化调整表演。

| 角色 | 本章依据 | 试音方向 |
| --- | --- | --- |
| 旁白 | 交代三轮测验、人物反应与萧炎往事 | 中文有声书旁白，清楚克制，给成绩公布和人群反应留出间隔。碑文可用同一音色，读得简短。 |
| 测验员 | 中年男子。向萧炎报成绩时漠然，对薰儿开口时罕见地带笑，语气略显恭敬 | 中年男声，咬字利落。报数与点名语速平稳，对薰儿开口时放缓一点，使用同一个参考音色。 |
| 萧炎 | 少年。受嘲讽时压着情绪，面对薰儿时有苦涩、自嘲和尴尬 | 略偏低的少年男声，音量收着。心声更近、更轻，回应薰儿时保留短停顿，尾声的笑带一点局促。 |
| 萧媚 | 约十四岁。拿到成绩后得意，随后看到萧炎，想起往事时轻叹 | 明亮、稍快的少女声。得知成绩时短促上扬，叹息时收轻。往事由旁白讲述。 |
| 萧薰儿 | 当众神情平静。见到萧炎时柔声称呼，认真鼓励，最后略带羞涩 | 清澈、平稳的少女声。向测验员道谢时简短从容，和萧炎说话时更暖。最后的坦率话语前停一拍。 |
| 未署名围观者 | 正文分开描写嘲弄、惋惜、羡慕和惊叹，未逐句交代身份 | 可用不同的短句音色区分态度，以匿名围观者标注。群声的具体分配属于制作选择。 |

人物状态和说话归属见[书旗中文第一章](https://t.shuqi.com/v2/query/53258/819384.html)及[WebNovel 第一章](https://www.webnovel.com/book/battle-through-the-heavens_8093990805004205/the-fallen-genius_21770745583562580)。

## 顺着正文标注

| 正文位置 | 归属与校对要点 |
| --- | --- |
| 萧炎测验 | 开篇只有成绩的短句随碑文出现，可作为旁白读屏。随后带姓名的完整宣布明确属于测验员。 |
| 宣布成绩后 | 几句评论都来自匿名围观者，其中也有惋惜。接着对昔日恭维和如今嘲讽的反问，可根据前后文作萧炎心声。第一句嘲讽里的反语引号保留在同一句。 |
| 萧媚测验 | 点名和完整报成绩归测验员。碑上显示成绩时可用旁白。萧媚有一声短促的欢呼，稍后有一声轻叹。人群赞叹单独标注，后面回顾萧炎往事的叙述归旁白。 |
| 萧薰儿测验 | 点名和之后的恭贺归同一名测验员。首次显示九段成绩可按碑文处理，之后惊叹的是围观者。萧薰儿简短道谢。 |
| 章末两人对话 | 萧薰儿先开口称呼。萧炎回问，随后两人交替说话。最后萧薰儿的认真鼓励和略带羞涩的补充用同一音色。她追上萧炎、两人并肩离开由旁白收尾。 |

在声轨工坊中导入所用版本的 TXT，先用「识别对白并标注」，再按上表逐场校对。优先检查碑文、围观者、萧炎的内心反问，以及带嵌套引号的句子。角色确认后再设置音色、生成整章并导出 WAV 与 SRT。
