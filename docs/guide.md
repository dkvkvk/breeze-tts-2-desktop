# 声轨工坊使用手册

[返回产品首页](../README.md)

## 安装与首次启动

下载方式见[快速开始](../README.md#快速开始)。安装程序允许直接输入安装路径。默认位置为 `D:\BreezeTTS2`，也可以选择其他位置。安装完成后，可从桌面或开始菜单打开应用。

首次启动时，应用会提供两个入口。选择「下载模型」获取默认 Q4_K，或选择「使用本地模型文件」打开已有的 Breeze TTS 2 GGUF 权重。模型加载完毕后即可开始合成。右上角「模型」面板可继续切换量化档位或下载其他版本。

## 选择模型

模型文件按实际字节数换算，以下使用十进制 GB。

| 档位 | 文件大小 |
| --- | ---: |
| Q4_K · dd2 | 2.46 GB |
| **Q4_K（默认）** | **2.54 GB** |
| Q6_K | 3.07 GB |
| Q8_0 · dd2 | 3.32 GB |
| Q8_0 · dd4 | 3.40 GB |
| Q8_0 | 3.57 GB |
| F16 | 6.28 GB |

下载会依次尝试 Hugging Face 和两个镜像，速度持续过低时会切换下载源。下载过程中可以取消，后续启动支持续传。

切换本地模型时，可以把权重放进数据目录的 `models\`，或直接在界面选择 GGUF 文件。推理服务按 `BREEZE_MODEL`、数据目录下的 `model-path.txt`、数据目录的 `models\`、运行时的 `models\`、运行时目录的顺序查找模型。手工修改 `model-path.txt` 时，请退出应用，把完整路径写在文件第一行，再重新启动。

## 保存音色

在「音色设计」中填写音色描述，为它命名，再点击「保存预设」。之后可以套用或删除该描述。预设只保存名称和音色描述，套用时保留编辑框中的台词。每个名称应唯一。

「音色库」的导入区支持拖放或多选文件。常见的 WAV、MP3、M4A、FLAC 和 OGG 文件可以导入，能够解码的音频会转为 24 kHz 单声道 16 位 WAV。建议选用 6–15 秒咬字清楚的单人录音，并填写与录音一致的逐字稿。导入预处理最多保留 30 秒。请使用自己录制或已获授权的音频。

音色包 `.btv` 使用 ZIP 格式，包含一份 `voice.json` 和参考音频。配置文件可按以下结构准备。

```json
{
  "name": "narrator",
  "ref_text": "与参考录音一致的逐字稿",
  "description": "语调平稳的旁白",
  "audio": "ref.wav"
}
```

从界面移除音色会把它从当前列表移除，已经保存的磁盘文件会保留。

## 长文配音与导出

单次支持最多 12,000 字、200 段和 20 分钟生成音频。换行开启新段。默认段间停顿为 0.5 秒。「使用音色设计的描述」可以把该页面当前的描述复制到配音脚本设置。

停止或遇到错误时，当前窗口保留已经生成的完整片段。保留原脚本和参数，再点击「继续生成」即可从下一段接着处理。你可以随时试听或导出目前已完成的内容。SRT 按每段实际音频时长和设定的停顿计算时间。

「保存配音草稿」会导出包含脚本、音色描述、音色标识和段间停顿的 JSON。下次可用「导入脚本或草稿」恢复设置。草稿引用的音色需要在当前音色库可用。生成的 WAV 和 SRT 需单独导出。

## 数据与备份

默认数据目录是程序安装目录。设置 `BREEZE_DATA` 可以使用其他目录。程序启动时会尝试从旧版的 `%LOCALAPPDATA%\BreezeTTS2` 迁移已有音色和有效的模型路径。

| 相对路径 | 内容 |
| --- | --- |
| `models\` | 下载的或手动放入的模型 |
| `voices\` | 已保存的参考音色 |
| `design-presets.json` | 音色设计预设 |
| `model-path.txt` | 手动选定的模型路径 |
| `logs\launcher.log` | 启动及推理服务日志 |
| `cache\` | Chromium 应用缓存 |

如需卸载，可在 Windows 的「设置 → 应用」中找到「声轨工坊」。卸载或更换安装位置前，请先备份需要保留的模型、音色和预设。
